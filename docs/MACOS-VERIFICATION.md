# Interactive macOS verification

Automated package tests and an unsigned build do not establish Finder integration, sandbox behavior, rendering fidelity, gestures, or accessibility. The following checks remain a release gate and must be recorded on a Mac. Use only synthetic or appropriately licensed fixtures. Do not publish personal paths, GPS, serial numbers, or metadata.

For gallery ratings, automated native checks assert accessibility labels and the image geometry used to position overlays. CI generates light/dark captures but does not automatically compare their pixels. The rendered rating number, gold color, absence of faint placeholders or stars on unrated images, and exact overlay placement require visual inspection. The automated assertions can pass even if the star drawing is missing.

Build using QUICKSTART.md, then run a locally signed app with the checked-in sandbox entitlements. An unsigned build or a package test is not proof of sandbox enforcement. Record macOS/Xcode versions, display backing scales, input devices, and actual results when performing these checks.

- [ ] Launch: window fills the available screen without native full screen; image fit is letterboxed and uncropped.
- [ ] Toolbar groups follow Display, Previous/Next, Gallery/Open/Refresh, and Sort/Metadata/Trash. The toolbar shows an image icon for Open, the existing grid icon without Gallery text, and a circled decreasing-lines icon for Sort & Filter. Check light/dark appearance and the 720-point minimum window width. Open launches the image picker; Gallery toggles views; Sort & Filter opens its popover. Verify tooltips, keyboard focus, and VoiceOver labels, including the active filter count after filtering and clearing.
- [ ] The viewing-mode toggle shows a fit-to-window icon and 100%, with Fit selected on launch. Switch both ways after manual zoom; the current image resets to the chosen mode. Double-click must update the toggle as well. Next/previous preserves the selected mode; entering Gallery, opening another image explicitly, reopening the closed viewer window, and relaunching reset to Fit, including with an older saved 100% default. Temporary scrolling leaves the selected mode unchanged; navigation reapplies that mode. Gallery replaces the zoom segments with layout and size controls; zoom segments return in image view. Verify each segment's tooltip and VoiceOver name/selected state.
- [ ] In Gallery Preview, View aligns with the capture/exposure caption at both 720 and 1000 points. Details stay pinned to the bottom, while the left-aligned image stays vertically centered above them.
- [ ] Gallery and Command-G show the authorized folder as a thumbnail grid. Decline folder access, then use Gallery to retry; canceling leaves the image viewer. Click/arrow to select and double-click/Return to view. Return to Gallery and verify the selection is visible. Check natural sort order, descending order, filters, no matches, Clear Filters, and a corrupt file among valid images. Scroll a large folder quickly, resize, and open a different folder while previews load; verify no stale thumbnails, bounded memory, and responsive navigation. Verify Move to Trash is disabled in gallery mode and re-enables after opening an image. Check filenames, aspect ratio/orientation, transparency, light/dark appearance, toolbar fit at 720 points, and VoiceOver selection/activation.
- [ ] Open via Finder and Open: one window is reused, requested image becomes selected, filters clear, sidebar collapses, and Fit to Window is restored. Repeat with the window closed and with a permission sheet open.
- [ ] Grant the exact containing folder; siblings appear. Decline; the opened image remains usable. Retry from File > Allow Folder Navigation. Choose a different folder; it must not be enumerated as though it were the containing folder.
- [ ] Switch between authorized folders and rapidly open/navigate images while decoding and scanning. Old results must never replace the new selection; grants must outlive dependent work.
- [ ] Navigate at both ends, through a single image, through corrupt/unreadable images, and with no filter matches. RAW files never enter the list; direct RAW opening shows the unsupported message.
- [ ] Verify every sort in both directions, equal primary values, missing metadata, and capture-time to creation-time fallback. Descending reverses filename ties too. Check multiple exact ratings and multiple file types: values within each group combine with OR, and the groups combine with AND. Include Unrated / 0 Stars, JPEG aliases, and HEIF aliases. Uncheck individual values and the final value in each group; an unchecked group includes all values. Verify selection retention, navigation, no matches, Clear Filters, checkbox states after reopening the popover and opening a new image, the active-group count, and the ordered status summary. Check checkbox keyboard/VoiceOver behavior and popover layout in light/dark appearance at the minimum window size. Rating checkboxes form two equal-width columns, with 0/1/2 down the left and 3/4/5 down the right; verify aligned rows and an unclipped Unrated / 0 Stars label.
- [ ] Move a disposable synthetic image to Trash using the toolbar and Command-Delete, both after Finder opening and File > Open, with and without a containing-folder grant. Cancel and verify unchanged bytes; confirm and recover it from Finder Trash. Verify next-image selection, wrapping, filtering, final-image empty state, and disabled actions while loading or without an image. Exercise a denied/read-only file or volume, missing file, image-named directory/symlink, a new open during confirmation/operation, and an active folder scan. Failures must not remove entries or silently permanently delete files. Verify native confirmation focus, Escape cancellation, VoiceOver, and toolbar fit at 720 points.
- [ ] Relaunch: saved sort/direction survive, viewing mode starts at Fit to Window, and filters and sidebar reset. Navigation retains active filters/sort/sidebar.
- [ ] Compare 100% on 1x and 2x backing displays and move the window between them. Equal pixel-size images tagged at 72 and 300 PPI must render at equal sizes. Resize and expand/collapse metadata while in fit mode.
- [ ] Test scroll up/down using a mouse and trackpad with natural scrolling both enabled and disabled. Double-click from fit to 100% over several off-center regions: the clicked image point stays under the cursor unless limited by an image edge. Double-click again to fit, including when 100% was chosen in the toolbar. After manual zoom, double-click selects 100% (or fit if already exactly at 100%). Drag to pan, then navigate forward/backward across landscape, portrait, differently sized, and small images; 100% and the relative viewport-center position should persist, constrained by image edges. - [ ] Inspect synthetic asymmetric orientation fixtures for all eight EXIF orientations. Compare tagged sRGB and Display P3 colors, and PNG transparency, against a trusted color-managed viewer. Test JPEG and HEIC/HEIF from representative encoders, including missing metadata.
- [ ] Compare sidebar field names with docs/PRODUCT.md. Confirm missing fields are omitted, source dimensions do not change with zoom, and sidecars do not affect metadata/ratings.
- [ ] Verify Sort & Filter opens/dismisses, all labeled controls apply immediately, active filters remain visible in the footer, and Clear Filters restores the image set. Check actionable empty/error states and loading feedback. During arrows, the previous image and zoom/pan must remain visible beneath a compact translucent spinner/filename box until replacement, with no blank canvas flash. Check long filenames, rapid reversals, Reduce Transparency, and VoiceOver loading feedback.
- [ ] Test VoiceOver labels, keyboard focus, menu shortcuts, selectable metadata, light/dark appearance, minimum window size, and sidebar scrolling with lengthy comments/paths.
- [ ] Compare hashes of all input images before and after viewing. Confirm no image, sidecar, or catalog files are created or modified.
- [ ] Exercise a near-limit image and an image over 64 megapixels, then continue navigating. Measure resident memory during repeated rapid selections; distinguish decode working memory from retained image data.
- [ ] Check thumbnail ratings from one through five: only that many filled gold stars appear inside the upper-left image edge, with no faint placeholders. Unrated and zero-rated images have no stars. Verify portrait/landscape placement, light/dark contrast, rating announcements in VoiceOver, and correct ratings after scrolling or changing filters.
- [ ] Revisit images and scroll back through the gallery to verify cache reuse. Full-resolution retention is capped at 1 GiB or ten images, and thumbnails have a separate 1 GiB cap without a count limit. Replace/delete a file while viewing other thumbnails, then revisit it; check refreshed pixels or a recoverable error. Account for visible images, active decoding, metadata, and rendering buffers separately from the two cache budgets.
- [ ] Navigate forward and backward through cached images: neither direction should flash a loading overlay. Navigate to an uncached or modified image and check loading feedback while decoding. Rapidly switch from a loading image to a cached one; the old overlay must disappear and no delayed overlay may cover the final image.

- [ ] Test navigation through a folder of large photos: paced steps, held arrows, direction reversals, and a new explicit open during loading. Confirm the newest selection wins and unchanged neighbors are reused without changing 100% detail or metadata. Replace/delete a viewed file externally and revisit it; verify updated pixels/metadata or a recoverable error.

- [ ] In both image and gallery views, replace an image externally, change its embedded rating, add files, rename files, and delete files (including the originally opened file). Confirm automatic updates, current filters/sort/sidebar and surviving selection, refreshed thumbnails/pixels/metadata, and usable empty/error states. Repeat with rapid saves and while a Trash confirmation sheet is open. Test the signed sandboxed app and a removable volume.
- [ ] Decline folder access and edit, delete, then recreate only the opened file. Confirm automatic reload after roughly one second, recoverable errors, and no sibling discovery. Grant the folder later and confirm new/deleted siblings update automatically. Open a different folder while updates are pending and confirm old events cannot replace it.
- [ ] Use Refresh and Command-R in both views, including unchanged-size/timestamp replacements, no matches, a missing/corrupt image, and a folder that becomes unreadable. Verify refresh does not reset sort/filter/sidebar or the current view. Check that the button remains available at 720 points and announces its purpose in VoiceOver.
- [ ] Verify the image-view footer shows the correct number of filled gold stars for ratings 1 through 5, with no placeholders for zero/missing ratings. Check accessibility announcements, light/dark contrast, compact layout with active filters and metadata, and that stars disappear during loading, errors, and Gallery. Review the `viewer-rating-*` native captures.
