# Real-photo regression fixture

`DSCF2143-LR.jpg` is the original, unmodified image supplied by the repository owner for navigation-performance and metadata regression testing. The owner explicitly authorized publishing the image and all its embedded metadata, including GPS coordinates and altitude, on November 5, 2026. This is a specific exception to the repository's general rule against committing personal photos or metadata.

The image is a 4085 × 6128 JPEG from a Fujifilm X-S20. Tests cover its shooting details, capture-time offset, GPS coordinates, altitude, full-resolution decoding, and unchanged source bytes. The performance tool uses this same fixture; it does not generate or substitute a smaller photo.
